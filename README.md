# 📊 Student Performance Analysis

## 📌 Project Overview

This project takes student marks from a CSV file and uses **Python, Pandas, and Matplotlib** to analyze their performance.

The program calculates total marks, average marks, grades, subject-wise averages, and identifies the top-performing student.

## 🚀 Features

* Read student data from a CSV file
* Calculate total marks
* Calculate average marks
* Assign grades automatically
* Find the top-performing student
* Calculate average marks for each subject
* Display grade distribution
* Create a subject-wise performance chart
* Save the analyzed results as a CSV file

## 🛠️ Technologies Used

* Pandas
* Matplotlib
* CSV

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Go to the project folder:

```bash
cd Student-Performance-Analysis
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the Python program:

```bash
python main.py
```
